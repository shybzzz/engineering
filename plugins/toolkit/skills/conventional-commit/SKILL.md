# Conventional Commits

Приклад скіла — заміни або видали його під свої потреби.

## Формат

```
<type>(<scope>): <короткий опис у теперішньому часі, без крапки>

<тіло: що і навіщо змінено — за потреби>
```

## Типи

- `feat` — нова функціональність
- `fix` — виправлення багу
- `refactor` — зміна коду без зміни поведінки
- `docs` — тільки документація
- `test` — тести
- `chore` — конфіги, залежності, інфраструктура
- `perf` — оптимізація продуктивності

## Правила

1. Опис — англійською, до 72 символів, у наказовому способі ("add", не "added").
2. `scope` — назва модуля/пакета, якщо зміни локалізовані; інакше пропусти.
3. Одна логічна зміна = один коміт. Якщо staged-зміни різнорідні — запропонуй розбити.
4. Breaking change — додай `!` після type і поясни в тілі.
